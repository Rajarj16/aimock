5. How to read this report

Golden set
A list of searches where we already know the correct answer, like an answer key.
Hit rate@5
Out of all searches, how often the right page appeared in the top 5 results.
Hit rate@1
How often the right page was the very first result.
MRR
Score for ranking quality: 1.0 means the right page is always first; 0.5 means usually second.
No-result accuracy
For nonsense or unrelated searches, how often the system correctly returned nothing.
Cross-patient leak
Whether a search ever returned another patient's record. Must always be zero.
Latency p50 / p95
Typical response time, and the time 95% of searches beat.

6. Method

Black-box evaluation through the search API. Each golden-set query is sent as a real request; the returned documents and page numbers are compared with the expected answer. Metrics are calculated over the whole set and compared with agreed targets. Test data: synthetic or de-identified records only; no real patient information is used. Results reflect this golden set and this build only, and should be re-run after any model or configuration change.
